# VAN 결제 전문 규격서 (`VanPacketCodec`)

## 1. 프레임 구조
모든 요청/응답 전문은 아래의 바이너리 프레임 구조를 따릅니다.

| 오프셋 | 필드 | 길이 | 설명 |
| :--- | :--- | :--- | :--- |
| `0` | `STX` | 1 byte | `0x02` (프레임 시작) |
| `1..4` | `LEN` | 4 bytes | `BODY` 바이트 길이 (ASCII 0-패딩 4자리, 예: `0048`) |
| `5..5+N-1` | `BODY` | N bytes | `FS (0x1C)`로 구분된 UTF-8 필드 문자열 |
| `5+N` | `ETX` | 1 byte | `0x03` (프레임 종료) |
| `6+N` | `LRC` | 1 byte | `LEN`부터 `ETX`까지 모든 바이트의 XOR 체크섬 |

## 2. 전문 코드 (`MsgType`)
| 요청 코드 | 응답 코드 | 거래 구분 |
| :--- | :--- | :--- |
| `D1` | `D2` | 신용카드 승인 |
| `D4` | `D5` | 신용카드 취소 (원승인번호, 원거래일자 포함) |
| `E1` | `E2` | 간편결제 승인 (카카오페이/네이버페이 등) |
| `C1` | `C2` | 현금영수증 발급 |
| `C4` | `C5` | 현금영수증 취소 |

## 3. 응답 코드
- `0000`: 정상 승인 / 정상 취소
- `E001`: 한도초과 또는 단말기 거절 (본 포트폴리오에서는 **결제금액 `99,999원`** 입력 시 의도적 거절 테스트 가능)
