# 고객사 현장 장애 대응 매뉴얼

## 1. 영수증 프린터 / 바코드 스캐너(COM 포트) 미응답
- **증상**: 영수증 출력이 되지 않거나 바코드 스캔이 입력되지 않음.
- **원인**:
  1. Windows 장치 관리자에서 USB-to-Serial 드라이버의 COM 포트 번호가 변경됨.
  2. 타 프로세스(기존 POS 잔류 프로세스 등)가 COM 포트를 점유 중임.
- **조치**:
  - `주변기기 / VAN 전문 모니터` 탭에서 상태 확인 (`Connected` vs `Simulated`).
  - 하드웨어 미연결 환경에서는 자동으로 `Simulated` 모드로 전환되어 매장 영업이 중단되지 않도록 설계됨.

## 2. VAN 단말기 승인 실패 / 타임아웃
- **증상**: 카드 결제 시 `결제 승인 실패 [E001]` 발생.
- **조치**:
  - `본사 동기화 / 장애 진단` 탭의 `DiagnosticLogs`에서 `[REQ]` 및 `[RES]` Hex 전문 확인.
  - 단말기 전원/케이블 및 정산 대기 상태 점검 후 재시도.

## 3. 본사 서버(HqApi) 네트워크 단절 시 매출 처리
- **설계 원칙 (오프라인 우선)**:
  - 가맹점 POS는 로컬 **MSSQL**에 주문과 `SyncOutboxItems`를 단일 트랜잭션으로 저장하므로 인터넷 단절 시에도 정상 판매 가능.
  - 네트워크 복구 후 `본사 동기화 / 장애 진단` 탭에서 `미전송 Outbox 동기화 (Push)`를 실행하면 멱등성(`EventType:AggregateId`)을 보장하며 누락 없이 본사에 반영됨.
